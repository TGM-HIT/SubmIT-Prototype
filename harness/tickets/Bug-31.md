# Bug-31. Show group members by name in student Formal proposals

## Intent

When a student starts or edits the allocated group's Formal proposal, the contribution form asks them to add allocated group members and enter each member's student ID. Students should instead see the complete finalized group roster, identify each member by name, and enter that member's contribution in a tab for them. This avoids asking students to know or transcribe account IDs and prevents manually adding or omitting group members.

## Source (when applicable)

The owner confirmed that a separate access-controlled roster response is authorized, returning each member's ID and display name only to students in that finalized group. IDs may associate each member's fields with the existing request payload, but must not be shown in the student interface. The existing selection flow is described in [Feature-22](./done/Feature-22.md).
