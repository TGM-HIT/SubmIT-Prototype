# Lesson proposal: align Evaluator artifact permissions with run workflow

The Evaluator explicitly declined to write `evaluation-1.md` because [evaluator.md](../roles/evaluator.md) says it never edits, while this run's workflow required the Orchestrator to preserve the verdict as a numbered evaluation artifact. Update [evaluator.md](../roles/evaluator.md) to authorize writing only the exact assigned `evaluation-N.md` artifact, and update [orchestrator.md](../roles/orchestrator.md) to include that path in each Evaluator dispatch. This would let the Evaluator own its verdict record without relaxing its prohibition on editing code, tickets, or other run files.
