## 1. Have the Ticket Author name existing tests coupled to a changed fixture

**What prompted it.** The ticket told the Implementor to extend `TestingAccountsConfigurationTest` and `TestingAccountsInactiveProfileTest`. The sentence belongs near the existing instruction to use `harness/templates/ticket.md` for the mechanical checks structure. A matching optional hint in the template's "Mechanical checks" comment would be nice but is not required.

**Owning document.** `harness/roles/ticket-author.md`, with an optional note in `harness/templates/ticket.md`.
