# Lesson proposal: make evaluator artifact ownership explicit

The Evaluator reported that it did not save `evaluation-1.md` because its role contract says it is read-only and never edits, even though the run workflow expects a numbered evaluation artifact. Update [evaluator.md](../roles/evaluator.md) to explicitly permit writing only the assigned `evaluation-N.md` verdict artifact while continuing to prohibit edits to code, tickets, and other files, and update [orchestrator.md](../roles/orchestrator.md) to provide that exact artifact path when dispatching each Evaluator. This resolves the conflict at both the evaluator's permission boundary and the orchestrator's handoff.
