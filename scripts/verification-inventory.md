# Archived verification-tool inventory

## Boundary and discovery

This is the bounded audit made at implementation start on **2026-11-07** for Dev-70. The implementation baseline was `119b1261dfc797a83636ab4107e0180c18736cb8`; the current checkout also contained the Orchestrator's temporary exact-path allowance commit `7d69f65de50404a7016784fea7977e0e082ad416`. Discovery covered the complete `harness/runs/archive/` tree at that time, every run directory's `evidence/` subtree, all descendants of each evidence root, nested evidence directories, and paths rather than only files with familiar extensions. The procedure did not execute archived code or use archived runs as a dependency for the shared commands.

The reproducible invocation and machine-readable candidate/hash output are retained at `harness/runs/Dev-70-20261107-1327/evidence/archive-discovery.py` and `harness/runs/Dev-70-20261107-1327/evidence/archive-discovery-result.json`. Invocation:

```sh
python3 harness/runs/Dev-70-20261107-1327/evidence/archive-discovery.py \
  --archive-root harness/runs/archive \
  --baseline-hashes harness/runs/Dev-70-20261107-1327/evidence/archive-source-hashes-before.tsv \
  --inventory scripts/verification-inventory.md \
  --output harness/runs/Dev-70-20261107-1327/evidence/archive-discovery-result.json
```

The discovery used sorted `os.walk(..., followlinks=False)` traversals. It considered Python, JavaScript, Node `.mjs`, shell, Ruby, Perl, PHP, PowerShell, batch, Java, Gradle/Groovy, and TypeScript source extensions; executable files; and extensionless regular files outside excluded trees whose first bytes indicated a shebang. It filtered the exact root `bugs-and-ideas.md` and the protected `.env`, `docker.env`, and workbook filenames before any content read. The exact root `bugs-and-ideas.md` was not read or inspected. Other run artifacts, logs, images, reports, and lessons were enumerated by path only and not opened.

Copied application/source snapshots and disposable contexts were excluded before promotion analysis by path components such as `baseline`, `host-context`, `docker-context`, `evaluator-host-context-2`, `checker-context`, `disposable-frontend`, and `dev33-java-fixtures`. Build outputs, dependency caches, vendor trees, generated files, and bytecode caches were excluded by components such as `build`, `target`, `dist`, `generated`, `node_modules`, `vendor`, `.gradle`, `__pycache__`, `venv`, `.venv`, and `site-packages`. Candidate-like source files within those trees are copied inputs or generated outputs, not independent evidence tools. Directory and file symlinks were enumerated but not followed.
